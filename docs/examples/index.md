# Examples

Complete scripts to copy and adapt. Each is one file using the SDK and the standard library.

| Example | What it shows |
| --- | --- |
| [A session file](session-file.md) | SMS login once, the cookie saved and reused, a new login when it expires |
| [Find a category](find-category.md) | Search the tree by name and print a ready `properties` template for a category |
| [Post from JSON](post-from-json.md) | Ads described in JSON files, checked, photos uploaded, posted, results written back |
| [Export to CSV](export-csv.md) | All ads of the account by tab, in a spreadsheet |
| [A prolong job](prolong-job.md) | Prolong expired ads every morning |
| [Django](django.md) | A model for ads, a management command and the session in the database |

The repository has two more scripts in [examples/](https://github.com/qiyascc/tapaz-python-sdk/tree/main/examples): posting an apartment and listing ads with the async client.
